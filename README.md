# 모닝케어

주모닝의 체온, 강급량, 복약 일정을 보호자들이 함께 기록하는 한국어 반응형 웹 앱입니다. Python 표준 라이브러리와 SQLite만 사용합니다.

## 기능

- 보호자 계정과 강아지 프로필을 분리해 관리합니다.
- 초대 코드 없이 가입하면 테스트 프로필 `주모닝 · 2017년생 · 바베시아`와 2026년 10월 6~7일 체온·강급(ml)·소변/대변·복약 기록을 만듭니다. 가입 시 초대 코드를 입력하면 기존 프로필에 바로 참여합니다.
- 강아지별 초대 코드로 다른 보호자를 연결하면 동일한 프로필과 건강 기록을 함께 확인하고 기록할 수 있습니다.
- 체온 그래프와 측정 기록, 강급 시간·양 및 하루 총량을 확인합니다.
- 체온 그래프에 기준 하한 37.5°C와 상한 39.2°C 선을 표시하고 소변·대변 및 3단계 활력 징후를 기록합니다.
- 첫 복약 시간을 기준으로 8시간 간격의 하루 세 번 일정을 보여주고 복용을 체크합니다.
- HTTPS 브라우저 알림을 켜면 앱이 열려 있는 동안 복약 예정 시각을 알려줍니다.
- 스마트폰 화면에서는 하단 탭과 기록 추가 버튼을 사용할 수 있습니다.
- PWA로 설치해 아이폰·아이패드와 Android 스마트폰 홈 화면에서 앱처럼 열 수 있습니다.

## 로컬 실행

Python 3.10 이상이 필요합니다. 프로젝트 폴더에서 실행하세요.

```bash
python3 server.py
```

브라우저에서 `http://localhost:8000`을 열고 보호자 계정을 만듭니다. 로컬 데이터베이스는 `data/morning.db`에 저장됩니다. 다른 데이터 위치나 포트가 필요하면 `DATABASE_PATH`, `PORT` 환경 변수를 설정할 수 있습니다.

### 같은 Wi-Fi에서 휴대폰으로 접속

Mac과 휴대폰을 **같은 Wi-Fi 네트워크**에 연결한 다음 프로젝트 폴더에서 아래 순서대로 실행합니다.

1. Mac의 Wi-Fi 사설 IP 주소를 확인합니다.

   ```bash
   ipconfig getifaddr en0
   ```

   주소가 나오지 않으면 `ipconfig getifaddr en1`도 확인하세요. 예를 들어 `192.168.1.23`이 표시되면 그 주소가 Mac의 Wi-Fi IP입니다.

2. 서버를 그 사설 IP에만 연결해 실행합니다. `192.168.1.23`은 위에서 확인한 실제 IP 주소로 바꿉니다.

   ```bash
   HOST=192.168.1.23 PORT=8000 python3 server.py
   ```

3. 휴대폰에서 같은 Wi-Fi에 연결한 채 브라우저를 열고 `http://192.168.1.23:8000`으로 접속합니다. 회원가입과 기록은 Mac의 `data/morning.db`에 저장됩니다.

서버가 실행 중인 터미널을 닫으면 접속이 끝납니다. 접속이 안 되면 Mac 방화벽에서 Python의 들어오는 연결을 허용하고, 두 기기가 같은 게스트 네트워크가 아닌지 확인하세요. 보안을 위해 **공유기에서 8000번 포트를 포트 포워딩하지 마세요.** 이 방식은 신뢰하는 사설 네트워크에서 개발·시험용으로만 사용하세요. 로컬 HTTP 주소에서는 PWA의 서비스 워커가 동작하지 않으며, 정식 PWA 설치 및 오프라인 앱 기능에는 HTTPS 배포 주소를 사용해야 합니다.

서버 실행 시 다른 기기에는 노출하지 않고 Mac 자기 자신에서만 접속하려면 `HOST=127.0.0.1 PORT=8000 python3 server.py`를 사용합니다. Docker/Render 배포에서는 플랫폼의 네트워크 바인딩 요구사항에 맞춰 기본 `HOST=0.0.0.0`을 사용합니다.

## 인터넷에 배포

Render Blueprint를 사용하도록 `render.yaml`과 `Dockerfile`을 포함했습니다.

1. 프로젝트를 본인 GitHub 저장소에 올립니다.
2. Render에서 **New → Blueprint**를 선택하고 해당 저장소를 연결합니다.
3. Blueprint가 생성하는 `morning-care` 서비스를 배포합니다. 배포 후 Render 대시보드의 서비스 URL(예: `https://morning-care.onrender.com`)로 어느 네트워크에서든 접속할 수 있습니다.
4. 외부에는 웹사이트 주소만 공개됩니다. 보호자 계정으로 로그인해야 강아지 프로필과 기록을 볼 수 있고, 기존 강아지에 참여하려면 보호자가 공유한 초대 코드가 필요합니다.
5. 소유자는 앱의 **가족 초대하기**에서 초대 코드를 공유합니다. 다른 보호자는 가입 시 코드를 입력하거나 로그인 후 **초대 코드 입력**에서 참여할 수 있습니다.

Blueprint는 SQLite 파일을 유지하기 위해 영구 디스크가 연결된 Render Starter 서비스를 사용합니다. 이 플랜 및 저장 공간은 무료가 아닐 수 있으니 배포 전에 Render의 현재 요금을 확인하세요. 영구 디스크가 없는 임시 파일 시스템에서는 재배포·재시작 시 기록이 사라질 수 있습니다.

이 저장소의 변경사항을 GitHub에 올린 다음 Render에서 Blueprint를 생성해야 공개 URL이 만들어집니다. Render 계정과 배포 권한은 저장소 소유자가 직접 연결해야 하며, 앱은 아직 자동 배포되지 않았습니다.

### 관리자 계정

관리자는 모든 강아지 프로필, 보호자 계정, 케어 멤버십, 건강 기록을 읽기 전용으로 확인할 수 있습니다. 관리자 계정은 가입 화면에서 만들지 않으며 비밀번호를 코드나 저장소에 넣지 않습니다.
관리자 환경에 테스트 프로필이 아직 없다면 `주모닝 · 2017년생 · 바베시아`와 지정 샘플 건강 기록이 한 번 생성되어 관리자 전체 데이터 화면에서 확인할 수 있습니다.

- 로컬 실행 시 서버 시작 명령에 `ADMIN_EMAIL`과 16자 이상의 강력한 `ADMIN_PASSWORD`를 환경 변수로 전달합니다.

  ```bash
  export ADMIN_EMAIL=admin@example.com
  read -s 'ADMIN_PASSWORD?관리자 비밀번호 (16자 이상): '
  echo
  export ADMIN_PASSWORD
  python3 server.py
  ```

- Render에서 Blueprint를 만들 때 `ADMIN_EMAIL`, `ADMIN_PASSWORD` 값을 입력합니다. 기존 Render 서비스라면 서비스의 **Environment**에서 두 값을 추가한 뒤 재배포합니다.
- 관리자 이메일로 로그인하면 **전체 데이터** 탭이 나타납니다. 설정된 환경 변수의 비밀번호를 바꾸고 재시작하면 해당 관리자 비밀번호도 갱신됩니다.
- 일반 보호자 계정은 전체 관리자 API를 호출할 수 없습니다. 관리자 응답에는 초대 코드가 포함되지 않습니다.

### 아이폰·아이패드에 설치

1. 배포된 HTTPS 주소를 **Safari**에서 엽니다.
2. 하단 **공유** 버튼을 누르고 **홈 화면에 추가**를 선택합니다.
3. **추가**를 누르면 모닝케어 아이콘이 홈 화면에 생깁니다. iOS의 Chrome 등 다른 브라우저에서는 Safari로 주소를 열어 추가하세요.

### 갤럭시 등 Android에 설치

1. 배포된 HTTPS 주소를 **Chrome** 또는 **삼성 인터넷**에서 엽니다.
2. 화면의 **앱 설치** 안내를 누르거나 브라우저 메뉴에서 **앱 설치**, **홈 화면에 추가**를 선택합니다.
3. 설치를 확인하면 앱 목록과 홈 화면에서 모닝케어를 열 수 있습니다.

URL로 방문한 사용자는 로그인 전에 설치할 수 있고, 앱 셸은 오프라인에서도 열리도록 캐시됩니다. 건강 기록과 로그인은 서버에 연결되어야 하며 API 데이터는 기기에 오프라인 캐시되지 않습니다.

현재 복약 알림은 앱이 열린 브라우저에서 동작하는 알림입니다. 브라우저나 기기가 종료된 상태에서도 알림이 필요하다면 별도의 푸시 알림 서비스와 모바일 푸시 구성이 필요합니다.
